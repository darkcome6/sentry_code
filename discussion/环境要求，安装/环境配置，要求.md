# 哨兵机器人（sentry_code）环境配置与依赖清单

> 适用：Ubuntu 22.04 LTS (jammy) + ROS 2 Humble
> 硬件后端：`real`（真机 CAN）/ `mock`（模拟）/ `mujoco`（MuJoCo 仿真）

---

## 一、系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Ubuntu 22.04 LTS (jammy) |
| ROS 2 | Humble Hawksbill |
| 项目路径 | **必须纯英文路径**（中文路径会导致 rosidl 构建失败） |
| 内存 | 建议 ≥8G（MuJoCo 仿真推荐 12G） |
| 磁盘 | 建议 ≥40G 可用（colcon build + 缓存） |

---

## 二、基础环境安装（Ubuntu 22.04 + ROS 2 Humble）

### 1. 添加 ROS 2 软件源

```bash
sudo apt update
sudo apt install -y software-properties-common curl
sudo add-apt-repository -y universe
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu jammy main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
sudo apt update
```

### 2. 安装 ROS 2 Humble 基础 + 构建工具

```bash
sudo apt install -y ros-humble-desktop python3-colcon-common-extensions python3-rosdep
# 初始化 rosdep（可选，用于自动解析依赖）
sudo rosdep init
rosdep update
```

> `ros-humble-desktop` 已包含：rclcpp/rclpy、tf2、geometry_msgs、std_msgs、sensor_msgs、rviz2、joint-state-publisher 等基础包。

## 五、MuJoCo 仿真依赖（`mujoco` 模式必需）

| 包（apt 名） | 用途 | 本机已装版本 |
|---|---|---|
| `ros-humble-mujoco-vendor` | MuJoCo 库（3.4.0） | 0.0.9 |
| `ros-humble-mujoco-ros2-control` | ros2_control 的 MuJoCo 硬件插件 + 节点 | 0.0.3 |
| `ros-humble-mujoco-ros2-control-msgs` | 消息（自动依赖） | 0.0.3 |
| `ros-humble-mujoco-ros2-control-plugins` | 插件（自动依赖） | 0.0.3 |

安装命令：

```bash
sudo apt install -y ros-humble-mujoco-ros2-control ros-humble-mujoco-vendor
```

> 说明：
> - `spr_hw_interface` 中的本地 `MujocoInterface` 也直接依赖 `mujoco_vendor`（头文件 `<mujoco/mujoco.h>`），其 CMakeLists 里已处理 mujoco_vendor 导出 target 的相对路径 bug。
> - 若 apt 源无此包，可从上游源码编译：`github.com/MatejVenglar/mujoco_ros2_control`。
> - **已知坑**：`mujoco_ros2_control` 节点默认开启 `lock_memory`（`mlockall` 锁定全部内存）。
>   若本机 `RLIMIT_MEMLOCK`（`ulimit -l`）较小，控制器 configure 会报
>   `Resource temporarily unavailable`（EAGAIN）。需在 `sentry.yaml` 的
>   `controller_manager` 参数下设置 `lock_memory: false`（本项目已配置）。

## 七、Python 依赖

`spr_remote_control` 包：键盘源 `keyboard_remote` 仅使用标准库 + ROS 2 自带包：
- `rclpy`、`geometry_msgs`、`spr_msgs`（本项目自定义消息）
- 标准库：`select`、`termios`、`tty`、`sys`
- **无额外第三方 Python 包需要安装**

串口遥控源 `rc_serial_remote` 额外需要 **`python3-serial`**（pyserial，已写入 package.xml 的 exec_depend）：
```bash
sudo apt install python3-serial
```

## 八、构建本项目

```bash
cd /home/b/sentry_code        # 必须纯英文路径！
source /opt/ros/humble/setup.bash
colcon build --symlink-install   # 或普通 colcon build
source install/setup.bash
```

> 若只改了某个包的配置/launch，可增量构建：
> `colcon build --packages-select spr_ctrl_bring_up`
> ⚠️ launch 读取的是 `install/` 下的副本，改 `src/` 后**必须 rebuild 才生效**。

---

## 九、运行

```bash
./run_sentry.sh mock          # 模拟硬件（默认）
./run_sentry.sh real          # 真机（自动拉起 CAN）
./run_sentry.sh mujoco        # MuJoCo 仿真（默认平地 flat）
./run_sentry.sh mujoco rough  # 崎岖地形
./run_sentry.sh mujoco ramp   # 坡道
./run_sentry.sh mujoco jump   # 飞坡
```

键盘遥控（另一终端）：

```bash
source install/setup.bash

# 键盘遥控（mujoco / mock 无遥控器硬件时）
ros2 run spr_remote_control keyboard_remote

# 串口遥控（真机：DR16 接收机 DBUS 直连上位机串口）
ros2 run spr_remote_control rc_serial_remote --ros-args \
  -p device:=/dev/ttyUSB0 -p baudrate:=100000 -p parity:=even
```

## 十、环境注意事项（重要）

1. **路径必须全英文**：ROS 2 Humble 的 rosidl/CMake 无法在含中文路径下构建
   （报 `list index: 1 out of range`），项目需放在纯英文目录。
2. **MuJoCo 内存锁定坑**：见第五节，`lock_memory: false` 已写入 `sentry.yaml`。
3. **实时调度权限**（真机控制建议）：确保当前用户可设置 RT 优先级，
   必要时在 `/etc/security/limits.conf` 追加：
   ```
   <user>  soft  rtprio  99
   <user>  hard  rtprio  99
   <user>  soft  memlock unlimited
   <user>  hard  memlock unlimited
   ```
4. **增量构建**：改配置后记得 `colcon build --packages-select <pkg>`（见第八节）。
