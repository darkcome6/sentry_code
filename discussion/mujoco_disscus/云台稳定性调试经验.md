# 云台稳定性调试经验（MuJoCo 仿真 · 2026-08-28）

> 背景：哨兵机器人 mujoco 仿真（mujoco_ros2_control），键盘遥控（mode 3）目标为 0 时，
> 云台 pitch 的 `p_error` 发散。本文记录从"发散"到"稳定"的完整调试过程与最终配置。

## 一、现象演进（四步定位）

| 阶段 | 现象 | 判断 |
|------|------|------|
| 1 | pitch `p_error` 约 39s 后轻微起伏 → 40s 明显 → 约束不住 | 底盘耦合 |
| 2 | 底盘四轮 P 从 8→0.8 后，发散推迟（仍会散） | 确认能量源在底盘 |
| 3 | 锁死底盘横滚/俯仰后，改为 small_yaw → big_yaw → pitch 级联发散 | yaw 无阻尼 + 积分积累 |
| 4 | 给 yaw 加机械阻尼 + 位置环 D、去积分后稳定 | 收尾 |

## 二、根因（三层）

1. **底盘 freejoint（6DOF 浮动、无阻尼）**：轮子电机力矩反作用直接扰动浮动底盘，
   晃动能量只积累不衰减 → 机械耦合到云台（"浮木板"）。
2. **云台 yaw（small_yaw/big_yaw）无阻尼 + 有积分**：绕竖直轴、不受重力，
   `I=0.15` 把数值噪声"记账"越攒越多 → 攒到阈值后爆发。
   small_yaw 最敏感（J 最小 + 挂 0.25m 悬臂）→ 先散，再带动 big_yaw，最后 pitch。
3. **位置环 D 在 500Hz 下放大噪声**：`u_D = D·Δerr/T`，D=1.0 时对 0.001 rad 噪声
   输出 0.5 N·m，反而不稳定 → 用"模型层机械阻尼"替代（对真实速度阻尼，不放大噪声）。

## 三、最终配置

### 模型 `sentry_robot.xml`（底盘）
- `freejoint` → 3 平动 + 1 偏航 普通关节，全部加阻尼（锁死横滚/俯仰）：
  - `base_x / base_y / base_z` slide `damping=10`
  - `base_yaw` hinge `damping=5`
- 云台机械阻尼（模拟真实电机摩擦）：
  - `bigyaw_joint` `damping=1.0`
  - `small_yaw_joint` `damping=0.5`

### 控制器 `sentry.yaml`
| 关节 | P | I | D | 说明 |
|------|-----|-----|-----|------|
| pitch | 1.0 | 0 | 0.03 | DM4310，加阻尼防耦合传导 |
| small_yaw | 3.0 | 0 | 0.3 | GM6020，P 从 18 降下、去积分 |
| big_yaw | 8.0 | 0 | 0.3 | DM6006，P 从 18 降下、去积分 |
| 四轮（速度环） | 0.8 | 0 | 0 | M3508，P 从 8 降下 |

## 四、MuJoCo 相机跟随（不用手动拖视角）

- **Ctrl + 右键双击** 机器人某部件 → 相机进入 Tracking 跟随它
- **Esc** 回自由相机；左键拖 = 旋转视角；滚轮 = 缩放
- **Tab / Shift+Tab** 恢复被隐藏的左右 UI 面板
  （mujoco_ros2_control 启动时硬编码隐藏 `ui0/ui1_enable=false`）

## 五、注意事项（重要）

1. **这些是"仿真稳定基线"，不是"真机可用参数"**：占位惯量 + 机械阻尼都是仿真专用，
   真机靠 IMU 云台自稳 + 真实摩擦 + 底盘电控前馈，参数需按真实机械重标定。
2. **以后跑 ramp/jump（飞坡/翻车）场景要还原 freejoint**：当前改法锁死横滚/俯仰。
3. **云台转动会反作用底盘航向**（真实物理）：转弯时云台 yaw 一动底盘被反推，
   仿真无 IMU 自稳更明显，可加 base_yaw 阻尼或增大底盘偏航惯量缓解。
4. **位置环 D 慎用**：500Hz 下 D 放大误差噪声，优先用模型层机械阻尼。
